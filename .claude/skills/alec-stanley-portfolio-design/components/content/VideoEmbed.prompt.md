A 16:9 video block for simulation footage. Videos are hosted on YouTube, never as local files.

```jsx
<VideoEmbed youtube="https://youtu.be/XXXXXXXXXXX" caption="Torque-free motion in three dimensions" />
<VideoEmbed source="orbit_3d.mp4" caption="Full 3D numerical integration" />
```

Without `youtube` it renders a dashed slot naming the original file, so the URL can be pasted in later.
