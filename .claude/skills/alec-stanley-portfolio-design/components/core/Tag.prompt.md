Monospace metadata chip for technologies, tools and disciplines. Always lowercase or as-written tech names — never sentence case.

```jsx
<Tag>python</Tag>
<Tag tone="accent">ANSYS Fluent</Tag>
<Tag tone="data">Δv 2.4 km/s</Tag>
```

Group them in a flex row with `gap: var(--space-2)`. Never more than ~6 per card.
